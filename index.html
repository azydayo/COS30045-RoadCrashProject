About this dashboard

The final website will use national, state and territory, and First Nations hospitalised injury datasets to answer key questions through visualisation. This homepage provides the structure first, so charts can be added later once the processed datasets are ready.

Our Working Process

Comments, steps, and tasks completed during the development of this data visualisation project.

Review the national, state and territory, and First Nations hospitalisation injury datasets. Identify the main fields, including hospitalisations, bed days, road user groups, age groups, sex, remoteness areas, and injury categories.

Transform the raw data into smaller datasets for each dashboard section, including national trends, road user groups, age groups, state comparisons, First Nations comparison, and remoteness.

Plan which chart type best answers each question, such as line charts for trends, horizontal bar charts for ranking, heatmaps for age patterns, and grouped bars for comparison.

Create the homepage layout, hero section, topic cards, and navigation so users can understand the purpose of the dashboard before interacting with the final charts.

Replace placeholder sections with final charts using tools such as D3, Chart.js, Plotly, or SVG-based visualisations depending on the project requirements.
