Our Working Process

Comments, steps, and tasks completed during the development of this data visualisation project.

Review national, state and territory, and First Nations hospitalisation injury datasets. Identify the main fields: hospitalisations, bed days, road user groups, age groups, sex, remoteness areas, and injury categories.

Transform raw records into smaller KNIME outputs for national trends, road user groups, age groups, state comparisons, First Nations comparison, and remoteness.

Use line charts for trends, horizontal bars for rankings, a heatmap for age patterns, grouped bars for remoteness comparison, and indexed lines for population disparity.

Convert the homepage prototype into routed dashboard pages so each topic has a focused visualisation, supporting KPIs, and short evidence-based insight cards.

Read CSV files with D3, aggregate where needed, draw responsive SVG charts, and keep colours, typography, borders, and spacing aligned with the existing website style.
